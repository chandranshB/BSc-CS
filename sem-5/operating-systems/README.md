# Operating Systems Lab

Operating Systems lab practicals implemented in Python 3.

## Practicals

1. Process Creation and Management - fork(), exec(), and wait() system calls.
2. Thread Creation and Management - Multi-threading partial sum computation using threading.
3. CPU Scheduling Algorithms - FCFS, SJF (non-preemptive), Priority, and Round Robin scheduling.
4. Process Synchronization (Producer-Consumer) - Bounded buffer synchronization using semaphores.
5. Process Synchronization (Readers-Writers) - Readers-writers problem using semaphores.
6. Dining Philosophers Problem - Deadlock-free solution using semaphores.
7. Banker's Algorithm - Deadlock avoidance with safety check and resource request evaluation.
8. Contiguous Memory Allocation - First Fit, Best Fit, and Worst Fit allocation simulation.
9. Page Replacement Algorithms - FIFO, LRU, and Optimal page replacement policies.
10. Disk Scheduling Algorithms - FCFS, SSTF, SCAN, and C-SCAN head movement simulation.
11. File Allocation Methods - Contiguous, Linked, and Indexed file allocation simulation.

## How to Run

Run any practical directly with Python 3:

```bash
python 01-process-creation.py
python 02-thread-creation-and-management.py
python 03-cpu-scheduling-algorithms.py
python 04-process-synchronization-prod-con.py
python 05-process-synchronization-read-write.py
python 06-dining-philosophers-problem.py
python 07-bankers-algorithm.py
python 08-contiguous-memory-allocation.py
python 09-page-replacement-algorithm.py
python 10-disk-scheduling-algorithm.py
python 11-file-allocation-methods.py
```
